HTML / (HyperText Markup Language) adalah bahasa standar untuk membuat struktur halaman web. HTML menggunakan tag untuk menandai elemen seperti teks, gambar, link, tabel, dan lainnya, HTML di ciptakan oleh tim berners lee pada tahun 1991. HTML memiliki struktur sebagai berikut:

  1. <html>
  2. <head>
  3. <title>
  4. <body>

deklarasi yang di gunakan dalam html5 adalah <!DOCTYPE html>, perlu di ketahui deklarasi <!DOCTYPE> gak bersifat case-sensitive jadi bisa ditulis pake huruf besar maupun kecil. fungsi <!DOCTYPE> adalah untuk memberitahu ke browser tentang versi html yang di gunakan dalam dokumen tersebut.

MATERI DASAR

1. TAG HEADING

tag heading/judul, menyediakan 6 buah tag yaitu h1-h6, h1 merupakan ukuran text yang paling besar dan h6 adalah ukuran text yang paling kecil.

  • <h1>
  • <h2>
  • <h3>
  • <h4>
  • <h5>
  • <h6>
contoh penulisan nya
<h1>hello world</h1>

2. TAG PARAGHRAF

tag paraghrap di gunakan untuk menuliskan text biasa, tag <p> dapat dikolaburasikan dengan nilai-nilai berikut :

  • center
  • justify
  • left
  • right
contoh penggunaanya :
<p align="center"> halo sobat ngoding </p>

3. TAG <a>

tag <a> adalah tag untuk membuat link, tag ini dapat di gabung dengan gambar.

<a href="https://www.contoh.com">klik ini </a>

jika di gabungkan dengan gambar seperti ini

<a href="https://www.contoh.com">
<img src="contoh.jpg">
</a>

4. TAG BOLD

tag bold adalah untuk membuat text menjadi tebal

contoh penulisan nya seperti ini
<b> contoh </b>

5. TAG ITALIC

tag italic adalah tag untuk membuat text menjadi miring

contoh penulisan nya
<i> contoh </i>

6. TAG UNDERLINE

tag underline adalah untuk membuat text bergaris bawah

contoh penulisan nya
<u> contoh </u>

7. TAG TABEL

tag ini di gunakan untuk membuat tabel, Elemen tabel berisi property <tr> untuk menentukan baris (table row) yang di dalam nya terdapat property <td> untuk menampilkan data pada setiap cell tabel. untuk mendefinisikan table heading atau yang biasa di sebut judul tiap kolom menggunakan tag <th>...</th>.

<table>
<tr>
<th> no </th>
<th> nama </th>
<th> alamat </th>
</tr>
<tr>
<td> 1 </td>
<td> zhar </td>
<td> tangerang </td>
</tr>
</table>

TAG-TAG INPUT TYPE

8. TAG INPUT TYPE TEXT

tipe masukan text adalah jenis input yang digunakan untuk menerima input dalam bentuk text atau karakter, contoh penggunaan nya adalah untuk mengumpulkan informasi seperti nama, username, atau input berupa text lain nya, contoh :

username :
<input type="text" name="nama" placeholder="masukan username/nama">

9. TAG INPUT TYPE PASSWORD

tipe masukan password adalah jenis input yang digunakan untuk menerima input dalam bentuk text atau karakter dan akan tersensor secara otomatis, contoh :

password :
<input type="password" name="pass" placeholder="masukan password">

10. TAG INPUT TYPE BUTTON

tag input tipe ini adalah untuk membuat sebuah tombol

<input type="button" value="login">

tag tombol ini meiliki dua cara untuk membuat tombol cara ke dua seperti ini

<button> login </button>
